# 智能采摘 · 果实计数

基于 Qt 6 / C++ / QML 的果实计数桌面程序。应用启动时会由 C++ 在 `0.0.0.0:8080` 启动本地 HTTP 服务；摄像头上传苹果、橘子累计数量，界面收到后立即更新。客户端不直接连接摄像头。

## 构建运行

需要 Qt 6.4 或更新版本，并安装 Qt Quick、Qt Network 和 CMake。用 Qt Creator 打开 `CMakeLists.txt`，选择桌面 Qt Kit 后构建并运行。服务跟随应用启动；关闭应用时服务也会停止。不需要单独运行 Python 服务器。

## 摄像头接口

摄像头通过 HTTP `POST /api/counts` 上传完整累计数值：

```json
{
  "apples": 12,
  "oranges": 8
}
```

请求地址为 `http://<运行本程序电脑的局域网IP>:8080/api/counts`。例如 `http://192.168.1.20:8080/api/counts`。本机浏览器可用 `http://127.0.0.1:8080/api/counts` 查看当前 JSON 数量。GET 用于读取计数，POST 用于更新计数。计数保存在内存中，关闭程序后会清零；界面把最近 15 秒内收到上传视为摄像头在线。

若摄像头无法连接，请确认设备处于同一局域网，并允许 Windows 防火墙接收本程序的局域网连接。8080 端口被占用时，界面会显示服务启动失败。
